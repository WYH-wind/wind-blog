## F1 文章管理走查（即刻交付）

现状：`/admin` 已有完整增删改查——草稿/发布、置顶 + 顺序、拼音 slug 自动生成且可手改（旧链接 308）、标签编辑、图片上传（压缩转 WebP）、实时预览、友链与站点设置。

走查路径（站长自助）：

1. 访问 `/admin/login`，输入管理员密码（本地 .env 中 `ADMIN_PASSWORD_HASH` 对应的密码）。
2. **文章管理**：右上「新建文章」→ 输入中文标题观察 slug 自动生成 → 正文用工具栏或直接写 Markdown，右侧实时预览 → 「发布」（二次确认，成功后跳到前台文章页）或「保存草稿」。
3. **编辑与 slug**：列表点标题进入编辑；手改 slug 保存后，访问旧 slug 会 308 到新地址；已发布文章显示「保存修改 / 转为草稿」。
4. **友链 / 设置**：导航切换；设置里改站名/简介/关于页（Markdown），前台即时生效（revalidate）。

验收：站长能独立完成一次「写作 → 发布 → 修改 slug → 验证 308」闭环。
（未采纳：前台编辑入口按钮——站长未选，如需要随时加。）

## F1.5 编辑器改造（走查反馈，2026-10-03）✅ 已完成

站长走查后的三条改进 + 布局根因修复：

1. **草稿/发布拆分为独立按钮**（原来是状态下拉+单一保存）：
   - 新建/草稿：`保存草稿` + `发布`；发布需 `confirm` 二次确认，成功后跳转到前台文章页。
   - 已发布：`保存修改`（保持发布态）+ `转为草稿`（确认后下架）。
2. **标签选择器**（原为逗号分隔文本框）：
   - 已选 chips（× 移除）；输入框回车/按钮新建标签；「从文中提取」行 = 现有标签名出现在标题/正文中的候选；「现有标签」行展示其余可点选标签。
   - 服务端不变：标签仍按名称 upsert（`resolveTagIds`）。
3. **编辑区放大 + 格式工具栏**：
   - 布局根因：全局 main `max-w-2xl` 压住了后台 → 宽度下放到各页面，后台外壳 `max-w-6xl`，编辑器双栏（左编辑右元信息+预览），正文 textarea 视口高度自适应。
   - 工具栏：H2/H3、加粗（⌘B）、斜体（⌘I）、删除线、高亮、变色（5 色盘）、引用、列表、行内代码、代码块、链接、分割线、插入图片；操作作用于选区。
4. **变色/高亮的实现约束（安全）**：不引入 raw HTML。采用 `remark-directive` + 白名单映射：`:red[文字]`/`:blue[]`/`:green[]`/`:orange[]`/`:violet[]` → `<span class="wind-c-*">`，`:mark[文字]` → `<mark>`；白名单外的指令（含容器/叶指令、未知名称）整块移除，指令属性一律不透传（单测覆盖 XSS 场景）。

验收：全部落地并提交；单测 22 通过（新增 4 条指令用例），E2E 发布链路改写为「保存草稿 → 发布 → 跳转文章页」。

## F8 全局搜索弹窗 ✅ 已完成

- **交互**：头部搜索图标位置不变，点击后在页面顶端弹出面板（自顶部轻落动画，尊重 reduced-motion）；背景锁定滚动，点遮罩 / Esc 关闭。
- **即搜即得**：输入防抖 300ms → `GET /api/search?q=`（≤50 字符、内存限流 30 次/分/IP、`Cache-Control: no-store`）；结果实时更新，关键词高亮，支持 ↑↓ 选择、回车打开、鼠标悬停联动。
- **全局全文**：搜索范围从标题/摘要扩展到**正文**（个人博客量级顺序扫描可接受，暂不加 content trgm 索引）；标题命中 > 摘要命中 > 正文命中，同档按时间倒序；正文/摘要命中带来源小徽标。
- **路由**：`/search` 页面删除 → 301 到 `/`；sitemap 本就不含 /search，无需改动。
- 验收：E2E 覆盖「旧地址重定向 + 任意页弹出 + 标题命中 + 仅正文命中 + 回车直达」。

## F2 界面层中英双语（i18n）

**决策**：只做界面层。文章内容保持单语（作者写什么语言就是什么语言），不做内容翻译表。

### 方案要点

- 路由：`/[locale]` 段重组——默认 `zh`（无前缀，现有 URL 不变），`/en` 前缀英文；`/en/…` 与无前缀页面一一对应。
- 依赖：推荐 **next-intl**（App Router 段路由、静态渲染、客户端 hook 开箱即用）；备选自建轻量字典。**开放问题：依赖引入最终定稿在实现时确认。**
- 字典范围：导航、页脚、首页 hero、探索页、搜索、404、文章页 UI 词（阅读时长/目录/点赞/收藏/浏览）、RSS 元信息、隐私声明。**后台 /admin 保持纯中文，不双语。**
- 切换器：header 内「中 / EN」，互指当前页对应 locale 版本（保持路径参数与 slug）。
- SEO：`alternates.languages` 输出 hreflang（zh + en + x-default）；OG `locale` 随之变化；sitemap 同时收录双语言 URL；RSS 站点描述随 locale 输出两个 feed（/feed.xml 中文、/en/feed.xml 英文）。
- 日期：中文「2026年9月20日」/ 英文 "Sep 20, 2026"，均按站点时区。

### 影响面

`src/app` 全量移入 `[locale]` 段（admin 除外）、`src/messages/{zh,en}.ts`、header/footer/文章页组件 props 化文案、`sitemap.ts`、`feed.xml`、`opengraph-image`（不动）。

### 验收

- [ ] `/` 与 `/en` 内容一致仅语言不同；切换器往返不丢路径
- [ ] 页面源码含 hreflang 三条；lighthouse SEO 无回归
- [ ] 无硬编码中文散落在组件（字典统一出口）
- [ ] 404 / 表单错误态双语
- [ ] 单测与 E2E 随路由调整更新

## F3 页面自适应（全量审计）

**方案**：以 375 / 768 / 1024 / 1440 四档逐一审计所有前台页 + 后台页，修复发现的全部问题，并预先覆盖以下已知风险点：

- header 五个导航项 + 搜索 + 主题切换在 ≤400px 溢出 → 小屏收纳为汉堡菜单（简洁展开面板，Wind 风格）
- 文章页 GFM 表格在窄屏溢出 → 横向滚动容器
- 编辑器双栏在 lg 以下已堆叠，检查 768–1024 的间隙；textarea 触控体验
- admin 表单与列表在 375px 的换行/截断
- 触控目标 ≥ 44×44px；图片 `max-width:100%`；长单词/URL 换行（`overflow-wrap`）

**验收**：四档宽度 + 移动端 Safari 视口下无横向滚动、无遮挡、无文本截断；Playwright 增加一档 375px 视口的冒烟用例。

## F4 页面回退体验（理解待确认）

按以下理解实现（如与诉求不符请纠正）：

1. **文章页返回链接**：header 下方或文末「← 返回」——智能回来源（从探索/搜索/首页进入则 history.back()，直达则回探索页）。
2. **移动端返回顶部**：文章页滚动超过一屏后出现悬浮按钮（右下，风线圆环图标）。
3. **滚动位置恢复**：列表/探索页点进文章再返回，滚动位置保持在原处（App Router 默认行为，验证不被动效/骨架屏破坏）。

**验收**：三条路径手动验证 + 滚动恢复 E2E 一条。

## F5 探索页（标签 × 归档合并）

**决策**：合并为一个「探索」页 `/explore`，导航只留一个入口（首页 / 探索 / 友链 / 关于）。

### 方案要点

- 布局：顶部标题 + 标签云（chips，含「全部」）；主体为按年分组的时间轴列表。点击标签 → `?tag=slug` 过滤该标签文章的时间轴（**单选 v1**，多选列为后续可选）。
- URL 驱动：`/explore`、`/explore?tag=frontend` 均可分享；ISR + 参数级缓存。
- 旧路径兼容：`/tags` → 308 `/explore`；`/tags/[slug]` → 308 `/explore?tag=[slug]`；`/archives` → 308 `/explore`。
- 导航与 sitemap 更新；搜索入口保留 header 图标。

### 验收

- [ ] 时间轴 + 标签筛选工作正常，筛选后仍按置顶/时间排序
- [ ] 三个旧地址全部 308 到新地址
- [ ] 空态（无标签/无文章）友好
- [ ] E2E：筛选 + 旧地址跳转

## F6 页面切换过渡（View Transitions）

**决策**：只做页面切换过渡这一项，克制、轻。

### 方案要点（推荐 + 降级）

- 推荐：启用 Next `experimental.viewTransition` + React `<ViewTransition>`，默认过渡为 150–200ms 的淡入 + 4px 上移；文章页进入时标题区先入。
- 降级：不支持的浏览器（Firefox/Safari 旧版）自动无过渡，不报错；`prefers-reduced-motion: reduce` 时全局关闭。
- **开放问题**：React ViewTransition 在 19.3 仍偏实验——若实现中出现不稳定，降级为 CSS `@view-transition`（跨文档硬导航生效）+ 关键链接 `startViewTransition` 手动触发，任选其一以稳定为先。

### 验收

- [ ] 前进/后退/导航均有轻过渡；无闪烁/白屏
- [ ] reduced-motion 下零动画
- [ ] 不破坏 F4 的滚动位置恢复
